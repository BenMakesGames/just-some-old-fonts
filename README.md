# Old Fonts

Bitmap fonts from DOS, early Windows and classic Mac OS games and applications that can be shared.

Years are approximate. Each folder holds the untouched originals, a preview, the licence text, and a `COPYRIGHT.md` with the source, the evidence and a confidence rating. Mac, GEOS and raw DOS fonts also come as Windows `.FON` and `.FNT`.

## Using them

- **Windows**: double-click a `.FON`. All of them load on Windows 10.
- **DOS**: `.Fnn` and `CPnnn_nn.FNT` files are raw 8-pixel-wide glyph tables for text-mode font loaders.

## Copyright notes

- The folder's own `COPYRIGHT.md` and licence file apply. There is no blanket licence for this repo.
- In the US, "typeface as typeface" is not subject to copyright ([37 CFR 202.1(e)](https://www.copyright.gov/title37/202/37cfr202-1.html)). Other countries differ, and font names may be trademarks.
- This is a best-effort record, not legal advice.
